## 使用

1. 阅读说明，按平常的真实状态选择五点选项。
2. 默认选后自动下一题，可关闭；支持数字 1–5、Enter 和上一题。选择英文原题可核对翻译，难以判断的题可标记复核。
3. 32题全部完成才生成结果。第一屏是四字母、四个维度的分数条和一段短摘要。整体叙述、四维分述（通常表现 / 可以发挥的地方 / 压力下留意）、维度互动、场景建议默认折起，顶部锚点会打开并跳到对应章节。结果页文字由本地固定规则生成。可以复制或系统分享一段摘要；不提供结果文件下载或上传。
4. 默认不持久保存。主动勾选后保存到本浏览器 localStorage；共用设备时关闭保存或选择“换一位 / 重新开始”。同源其他标签页更新、清空草稿或换人后，旧页面会停止保存并提示，避免覆盖新答卷或恢复已经清空的数据。

## 来源与计算

- [原始题目、计分键、许可 PDF](https://openpsychometrics.org/tests/OJTS/development/OEJTS1.2.pdf)，本地副本 `sources/OEJTS1.2.pdf`。作者 Eric Jorgenson，2015-03-03。
- [开发说明](https://openpsychometrics.org/tests/OJTS/development/)。开发页及在线版包含不同题数叙述；本工具只采用以上32题PDF，不混用其他版本。
- [官方 MBTI 版权与许可](https://www.themyersbriggs.com/en-US/Support/Copyright-and-Permissions)。未复制其专有题库。
- [16Personalities 模型说明](https://www.16personalities.com/articles/our-theory)。未把 NERIS 的分数或 A/T 后缀混入本工具。

每题保留原序号与两极，1最靠左、5最靠右。四维均为8–40分，中点24；原版 >24 取 E/N/T/P，否则取 I/S/F/J。结果页同时显示原始分与刻度位置：`(分数 - 8) / 32 × 100%`。只有刻度位置落在 45%–55%（8–40 整数刻度上即 23、24、25 分）的维度显示 X；这是页面阅读约定，不是源量表规则或经过验证的置信区间。刻度百分比不是人群百分位、准确率或概率。

“标记复核”、中间项个数和前台作答时长不参与计分，也不用于判定回答有效性。没有暗中添加题目、删题、权重、人口学阈值、AI判型或认知功能推断。结果页的整体叙述、四维分述、维度互动和场景建议，由 `src/interpret.js` 的固定规则根据四维分数生成；整体叙述按四维方向和强度拼接固定句式，同一组分数得到同一段文字。它不调用 AI，也不改变计分，不是心理诊断、能力评价或经过验证的类型描述。

题目、中英文译文、难译说明及计分定义统一保存在 `sources/oejts-1.2.json`。每题的维度与方向是计算和公式展示的共同来源；测试另保留独立核对的预期分数与方向。部分原题涉及生活条件、活动、语言与文化偏好，不保证跨群体测量等值。

中文量表的后续研究目标与验收记录在 [中文量表验证计划](docs/measurement-validation.md)。该计划尚需评审者和真实研究数据，工程测试不代表心理测量验证。

## 开发与检查

开发和检查使用 Node.js 22 或更新的受支持 LTS 版本。构建及 Node 测试不依赖第三方库；浏览器回归测试使用锁定版本的 Playwright 开发依赖。

```powershell
npm ci
npx playwright install chromium firefox webkit
npm run build                  # 生成 index.html 与 publish/index.html
npm run check                  # 构建脚本和运行时代码语法检查
npm test                       # 计分、本地解读、草稿状态和构建校验测试
npm run build:check            # 只检查源码与两个产物是否一致，不写文件
npm run test:browser:chromium   # Chromium 用户流程回归
npm run test:browser            # 全部浏览器与窄屏项目
npm run verify                 # 语法、Node 测试、产物一致性及浏览器回归
```

`src/template.html`、`src/styles.css`、`src/app.js`、`src/core.js`、`src/interpret.js` 和题库由构建脚本嵌入单文件 `index.html`，并自动同步 `publish/index.html`。构建无需任何第三方依赖。只修改源文件后请重新构建。

应用版本来自 `package.json`，存储格式与翻译版本分别管理。现有 v1.0 草稿可迁移；只更新应用版本不会使兼容草稿失效。不兼容或损坏的草稿会提示，原数据不会被静默覆盖。

GitHub Actions 在 Node.js 22/24 上执行检查，浏览器回归针对生成后的 HTML，并保留失败时的 trace 和截图。CI 中的产物检查会阻止源码与已提交 HTML 不一致的变更；本工作流不自动发布网站。

页面不加载外部脚本、字体、统计或接口，也不上传答案或结果。资料链接会打开第三方网站。
