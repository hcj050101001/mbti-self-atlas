# 中文量表验证目标

本文件是后续研究计划，不代表研究已完成。当前 OEJTS 1.2 中文版仍为未经心理测量验证的试译；代码测试只能证明实现符合既定计分规则。

## 1. 固定可追溯的研究版本

- 以 `sources/oejts-1.2.json` 中的英文原题、中文译文、计分方向和 `translationVersion` 为研究输入。
- 在研究记录中保存应用版本、翻译版本、题库文件 SHA-256 和研究方案版本。
- 修改任何题意后建立新的翻译版本，保留修改理由；不同版本的数据不得在未说明的情况下混合分析。

验收：页面记录应用版本、翻译版本、题库与计分定义，并保留原始答案供本地复算。结果页可以在本机复制一段不含逐题答案的摘要，不提供文件导出，也不把结果页文字当作研究数据。

## 2. 完成翻译与理解评审

- 由具备双语能力和心理测量经验的评审者核对概念、两极方向、日常表达及文化语境。
- 对现有 `translationNotes` 标出的难译题逐项形成接受、修改或继续研究的结论，记录依据。
- 对目标使用人群开展认知访谈，记录受访者如何理解两端描述和五点选项，整理歧义与情境不适用问题。

验收：形成逐题评审记录、修订记录和最终待试测题库；不以单次机器翻译或文字流畅代替理解验证。

## 3. 先确定研究方案，再收集试测数据

- 明确目标人群、招募方式、主要研究问题、排除规则、缺失数据处理及重测间隔。
- 根据拟使用的分析方法和所需精度确定样本量及判定标准，记录依据，避免事后按结果调整标准。
- 分析四维分数的分布、内部结构、信度、重测稳定性，以及与适当外部测量的关系；涉及群体比较时评估测量等值性。
- 核对分类在中点附近的稳定性。页面当前的 45%–55%（23–25 分）中间带保持为展示约定，不将其当作统计置信区间。

验收：有可复核的方案、分析代码和技术报告，报告效应估计、不确定性、样本限制及不支持的解释，而不是只给一个“准确率”。

## 4. 将研究结论反映到产品中

- 按证据更新适用范围、解释文字和翻译版本；只有研究支持时才调整解释规则。结果页的解读文案属于编辑性规则，用于帮助自我观察，不作为测量证据。
- 计分规则或题意变化时，评估旧草稿和旧报告是否可继续比较，并提供明确的版本说明。
- 未完成上述验证前，保留“中文试译、非官方 MBTI、未经心理测量验证”的说明。

验收：发布说明中的每项可信度主张都能对应到已完成的技术报告，代码测试与测量证据分别记录。

参考：[International Test Commission：Guidelines for Translating and Adapting Tests](https://www.intestcom.org/page/14)。
